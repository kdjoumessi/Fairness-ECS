# Fairness-ECS
This repository contains the official implementation of the test-time explainability from the paper ["Beyond Predictive Fairness: Quantifying Attribution Consistency Across Demographic Groups in Diabetic Retinopathy Screening"](https://faimi-workshop.github.io/2026-miccai/).

## Data
The code in this repository uses the [EyePACS Retinal Fundus dataset](https://journals.sagepub.com/doi/10.1177/193229680900300315) available upon request.

## Training
The model was trained following repository for [An Inherently Interpretable AI model improves Screening Speed and Accuracy for Early Diabetic Retinopathy.](https://github.com/kdjoumessi/Sparse-BagNet_clinical-validation).
